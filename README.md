# Amazon ML Challenge 2026 - Business Entity Resolution

This repository contains an end-to-end entity resolution pipeline to match Source 1 entities against Source 2 and Source 3 entities. 

## Approach

1. **Text Normalization**: All business names and addresses are lowercased, non-alphanumeric characters are stripped, and whitespace is normalized using vectorized pandas operations.
2. **Blocking (Candidate Generation)**: To efficiently match 2.2M S1 records against a 10M+ S2/S3 pool without creating a dense matrix, we use three complementary blocking strategies:
   - **Exact Name Match**: Dictionary lookup for fast deduplication.
   - **Word TF-IDF Name Similarity**: Highly specific TF-IDF vectors (max_df=0.01) on business names, combined with sparse matrix dot products to rapidly retrieve top-K candidates over a set threshold.
   - **Exact Address Match**: Dictionary lookup for clean addresses longer than 10 characters.
3. **Feature Engineering**: For every candidate pair generated by blocking, we compute string similarities using `RapidFuzz` (fuzz ratio, token_set_ratio, partial_ratio) and Jaccard similarities on tokens. Length differences and exact match flags are also included.
4. **Matching Model**: A `HistGradientBoostingClassifier` trained on ground-truth matches predicts the probability of a match. We explicitly tune the threshold for the F0.5 metric (precision heavily favored) via the validation set.

## Reproducing the Solution

To fully reproduce the validation and final outputs, run the provided batch script. It creates a virtual environment (optional if already active), trains the model, evaluates validation, and outputs the final submission files.

```bash
run.bat
```

Alternatively, step-by-step:

1. **Install requirements**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run training & test inference**:
   ```bash
   python run_train_pipeline.py
   python src/main.py
   ```

3. **Outputs**:
   - `output/candidate_pairs.tsv`
   - `output/matching_results.tsv`

## Validation

The code will automatically run the official validation script:
```bash
python dataset/test/student_resource/utils/validate_submission.py \
    --matching output/matching_results.tsv \
    --candidate output/candidate_pairs.tsv \
    --test-dir dataset/test
```
